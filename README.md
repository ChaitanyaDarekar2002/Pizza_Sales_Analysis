# 🍕 Pizza Sales Analysis Dashboard | Power BI

An interactive **Pizza Sales Dashboard** built using Microsoft Power BI to analyze sales performance, orders, pizza categories, and size preferences.

### 📊 Key Features
- Total Revenue and Total Orders
- Average Order Value
- Average Pizzas Per Order
- Top-Selling Pizzas by Revenue
- Sales by Pizza Category
- Sales by Pizza Size
- Interactive Date Filter

### 🛠️ Tools Used
- Microsoft Power BI
- DAX
- Data Modeling & Visualization

### 🎯 Objective
To analyze pizza sales data, identify popular pizza categories and sizes, and gain insights into sales performance to support better business decisions.
